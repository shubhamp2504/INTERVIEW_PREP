## 🎯 System Design Framework

```
1️⃣ Requirements Clarification (5 min)
   └─ Functional & Non-functional requirements

2️⃣ Capacity Estimation (5 min)
   └─ Traffic, Storage, Bandwidth

3️⃣ High Level Design (10 min)
   └─ Components, APIs, Data Flow

4️⃣ Detailed Design (15 min)
   └─ Database Schema, Algorithms, Trade-offs

5️⃣ Bottlenecks & Scaling (5 min)
   └─ Single Points of Failure, Monitoring
```
