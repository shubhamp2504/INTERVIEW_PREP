## 🎯 How to Use This System

### 📥 Adding New Questions (Bulk Input)
Copy the prompt template from [`PROMPT_TEMPLATE.md`](./PROMPT_TEMPLATE.md) and paste your questions. The system will auto-organize them.

### 🔍 Searching
- Use `Ctrl+Shift+F` in VS Code to search across all files
- Use GitHub search if hosted online
- Browse by category using the table above
